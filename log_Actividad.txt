Ejercicio 3: Gestión de ramas

    1.-Creación de fichero
        Archivo creado: ramas.txt

    2.-Creación de rama nueva y cambio a ella para trabajar
        En terminal:
            git checkout -b nueva_rama
        Mensaje:
            Switched to a new branch 'nueva_rama'

    3.-Visualización de ramas en local y remoto
        En terminal:
            git branch -a
        Mensaje:
              master
            * nueva_rama
              remotes/origin/master

    4 y 5.-Modificación del archivo, añadirlo a la zona de intercambio temporal y commit
        En terminal (después de modificar):
            git add ramas.txt
            git commit -m "Cambios desde rama nueva"
        Mensaje:
            [nueva_rama 4a1d500] Cambios desde rama nueva
             1 file changed, 1 insertion(+)

    6.-Cambio a la rama master
        En terminal:
            git checkout master
        Mensaje:
            M       log_Actividad.txt
            Switched to branch 'master'
            Your branch is ahead of 'origin/master' by 2 commits.
            (use "git push" to publish your local commits)

    7 y 8.-Modificación del archivo, añadirlo a la zona de intercambio temporal y commit
        En terminal (después de modificar):
            git add ramas.txt
            git commit -m "Cambios desde rama master"
        Mensaje:
            [master 06c9d82] Cambios desde rama master
            1 file changed, 1 insertion(+)

    9.-Fusión de ramas
        En terminal (en la rama master):
            git merge nueva_rama
        Mensaje:

            CONFLICT (content): Merge conflict in ramas.txt
            Automatic merge failed; fix conflicts and then commit the result.

            >>>>>>> nueva_rama (Incoming Change)

    10.-Resolución de conflictos de forma manual
        En archivo ramas.txt se deja el texto resultante como se quiera y se guarda el archivo.

    11.-Finalización de fusión: Modificación del archivo, añadirlo a la zona de intercambio temporal y commit

            git commit -m "Paso 11: Finalizando fusión"
